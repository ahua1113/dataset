# V6.4 OA-only 全学科持续采集设计

日期：2026-10-28

## 目标

V6.4 将 V6.3 的学科配额、合法 OA 多来源兜底和本地去重机制收束为可在 Linux 服务器长期运行的最终版本。白名单期刊限定论文身份与质量，主学科覆盖决定采集优先级，已有论文始终先于网络请求恢复到统计快照。

## 单轮流程

1. 取得输出目录单实例锁；
2. 校验磁盘空间并读取本地 manifest 中仍有有效 PDF 的记录；
3. 为旧版缺失学科字段的论文按现有元数据重新分类；
4. 用 DOI、OpenAlex ID、标题、URL 和 SHA-256 恢复去重集合；
5. 计算当前各学科数量、期刊多样性、单刊占比与综述占比；
6. 通过 ISSN 校验 OpenAlex Source ID，只接收主发表期刊匹配、非撤稿、有 DOI 的 OA article/review；
7. 依次尝试出版社、合法预印本、PMC/Europe PMC、机构库及其他 OA 仓储；
8. 验证 HTTPS、robots.txt、响应类型、PDF 签名、大小和 SHA-256；
9. fsync 追加 manifest，并原子更新配额状态和量化报告；
10. 本轮达到目标或耗尽尝试预算后等待，下一轮重新建立网络客户端。

## 连续配额

配置中的基础目标仍为每学科 20 篇。连续模式读取当前数量最少的学科：

- 少于 20 篇时，本轮目标为 20；
- 最低数量达到 20 后，本轮目标为 40；
- 之后按 60、80、100……递增。

数量超过目标的学科不会继续无差别扩张，但仍可接收用于修复期刊多样性、单刊占比或综述占比的论文。默认约束为至少 3 本期刊、单刊不超过 40%、综述不超过 30%。

## 历史数据

正式输出固定为 `chemistry_dataset/papers/`。运行策略中被停用的低收益期刊不会参与新请求，但其历史成功论文仍参与所有统计。合并工具在写入统一 manifest 前完成 DOI/SHA-256 去重、文件签名核验和缺失学科补全。

若旧流程只留下孤立 PDF 记录，`tools/recover_manifest_metadata.py` 可从指定文件或
Git 历史 manifest 中按相同 SHA-256 恢复元数据。恢复后再按 DOI、OpenAlex ID、标题和
SHA-256 去重；不匹配的记录不会被猜测性补全。

## 量化报告

`chemistry_dataset/quantitative_analysis/quantitative_report.csv` 使用统一长表结构：

- `section` 表示总量、期刊、学科、年份、来源、质量或交叉统计；
- `dimension` 与 `value` 标识统计对象；
- `count` 与 `percentage` 保存数量和占比；
- 学科行额外保存目标、缺口、期刊数、最大单刊占比、综述占比和是否达标。

CSV 使用 UTF-8 BOM 并通过临时文件原子替换，便于 Excel 打开，也避免监控程序读取到半写入文件。

## 服务器可靠性

- PID 锁拒绝同一输出目录的并发写入，失效锁会自动清理；
- SIGINT/SIGTERM 转换为停止事件，等待可立即中断；
- 运行状态原子写入 `runtime_state_v6_4.json`；
- 每条 JSONL 写入后 flush 与 fsync；异常中断造成的不完整末行会被安全忽略；
- 每轮重建客户端，域名熔断不会永久延续到后续轮次；
- 连续失败采用最多 16 倍轮询间隔的指数退避；
- 可用磁盘低于阈值时暂停，不开始新一轮下载；
- 每刊尝试预算、域名熔断和全局尝试上限继续有效。

## 安全边界

仅使用无需登录的合法 OA 链接，遵守 robots.txt 和请求限速。不保存或使用账号、Cookie、校园认证信息，不处理验证码，不绕过付费墙或 Cloudflare，也不使用 Sci-Hub。许可证缺失时保留人工核验状态，不把“可下载”等同于“可再分发”。
